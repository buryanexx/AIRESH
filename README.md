# CTReshenie - Telegram Mini App

Приложение для расчета эффективности ИИ-фотосессии для маркетплейсов.

## Что это такое?

CTReshenie поможет продавцам на маркетплейсах:
- Рассчитать потенциальный рост CTR после обновления фотографий
- Увидеть наглядные примеры "До/После" для реальных товаров
- Оценить прирост заказов и улучшение конверсии

## Структура проекта

- `/src` - Исходный код React приложения
- `/bot` - Код Telegram бота
- `/public` - Статические файлы
- `/dist` - Собранное приложение (после `npm run build`)

## Установка и запуск

### Фронтенд (React)

```bash
# Установка зависимостей
npm install

# Запуск для разработки
npm run dev

# Сборка для продакшн
npm run build
```

### Telegram бот

```bash
# Переход в директорию бота
cd bot

# Установка зависимостей
npm install

# Создайте файл .env со следующим содержимым:
# TELEGRAM_BOT_TOKEN=ваш_токен
# APP_URL=url_вашего_приложения

# Запуск бота
npm start
```

## Деплой

### На VK Cloud

1. Зарегистрируйтесь на [VK Cloud](https://mcs.mail.ru/)
2. Создайте новый проект
3. Настройте CI/CD в GitHub Actions (файл `.github/workflows/deploy-vk-cloud.yml`)
4. Настройте секреты в репозитории:
   - `VK_REGISTRY` - URL реестра контейнеров
   - `VK_USERNAME` - Имя пользователя для реестра
   - `VK_PASSWORD` - Пароль для реестра
   - `VK_HOST` - IP-адрес вашего сервера
   - `VK_SSH_USERNAME` - Имя пользователя для SSH
   - `VK_SSH_KEY` - Приватный SSH ключ

### Настройка Telegram бота

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен и добавьте его в `.env` файл бота
3. Установите команды для бота:
   ```
   calculator - Открыть калькулятор эффективности
   cases - Посмотреть наши кейсы
   ```
4. Настройте WebApp URL в BotFather (команда /setdomain)
